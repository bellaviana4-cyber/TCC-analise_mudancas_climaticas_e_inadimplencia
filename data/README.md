\# Dados



Este diretório contém a estrutura de armazenamento dos dados utilizados

no projeto.



Os arquivos de dados não são versionados pelo Git devido ao seu volume.



\## Estrutura



\### `raw/bacen/`



Arquivos originais provenientes do Sistema de Informações de Crédito

do Banco Central do Brasil (SCR/BACEN).



\### `raw/atlas\_desastres/`



Arquivos originais provenientes do Atlas Digital de Desastres no Brasil.



\### `interim/`



Bases intermediárias produzidas durante as etapas de limpeza,

padronização e integração.



\### `processed/`



Bases finais utilizadas nas análises estatísticas e nos modelos.



Os dados brutos devem permanecer inalterados. Todas as transformações

devem ser realizadas por meio dos códigos disponíveis no projeto.
