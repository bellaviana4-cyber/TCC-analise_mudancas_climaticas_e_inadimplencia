# Documentação do projeto

A documentação acompanha o percurso da análise, desde a construção do painel até a interpretação dos resultados.

1. [Dados e variáveis](../data/README.md): fontes, modalidades excluídas, taxa de inadimplência e registros de desastres.
2. [Metodologia e sensibilidades](metodologia_e_sensibilidades.md): transformações, recortes, Granger, DLM e SARIMA/SARIMAX.
3. [Resultados](resultados.md): síntese das estimações, diagnósticos e comparação entre abordagens.
4. [Reprodução](reproducao.md): ambiente, arquivos, comandos e verificação da integridade.
5. [Construção e validação do painel](correcao_modalidades_20261104.md): recorte de crédito e verificações.
6. [Resumo numérico automatizado](resumo_execucao.md): contagens calculadas a partir das tabelas publicadas.

Para consultar as saídas, use o [índice de tabelas e figuras](../outputs/README.md). Para acompanhar a análise, use os [cinco notebooks principais](../notebooks/README.md).

Os documentos das etapas anteriores estão identificados no [histórico de desenvolvimento](historico.md). Eles preservam o percurso metodológico, mas podem apresentar bases, especificações e resultados distintos dos utilizados na versão final.
