# Histórico dos notebooks

Este diretório conserva os notebooks anteriores à unificação das metodologias de Granger, DLM e SARIMA/SARIMAX. Inclui as etapas exploratórias, análises nacionais anteriores e revisões intermediárias com outputs históricos.

Para reproduzir a **versão atual**, utilize exclusivamente os três notebooks na pasta [`notebooks/`](../): `01_granger_ufs_tipologias.ipynb`, `02_dlm_painel_aic_bic.ipynb` e `03_sarima_sarimax_estadual_nacional.ipynb`.

Os arquivos deste diretório são preservados para rastreabilidade; suas especificações e resultados podem diferir dos notebooks principais em razão de revisões metodológicas posteriores. Não apague nem misture seus resultados com os da versão atual sem indicar a proveniência.
